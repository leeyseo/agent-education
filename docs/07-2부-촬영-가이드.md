# 2부 촬영 가이드 (디자이너 편 EP6~EP8)

> 지금 2부(EP6~EP8)는 claude.ai 화면을 HTML로 다시 그린 모형으로 만들어져 있다. 이 문서는 나중에 실제 화면 녹화로 바꾸고 싶을 때 쓴다.

2부를 실제 화면으로 만들려면 claude.ai를 녹화해야 한다. 녹화는 사람이 직접 한다. claude.ai는 이용약관상 API 키 없이 스크립트로 조작할 수 없다. 이 문서대로 찍어서 파일만 넘기면, 자르기·확대·자막·내레이션은 나머지 도구가 처리한다.

- 걸리는 시간: 약 15분 (AI 답을 기다리는 시간 포함)
- 말할 필요 없다. 소리는 쓰지 않는다.

## 준비

### 1. 올릴 자료

`shorts/s2/rec/자료/`의 파일 4개만 쓴다. 전부 지어낸 가상 고객 자료다. 실제 고객 자료는 올리지 않는다.

| 파일 | 내용 |
| --- | --- |
| 모닝빵_2호점_기획서.pdf | 가게 소개, 2호점, 맡은 일, 사장님 요청 |
| 모닝빵_2호점_회의자료.pdf | 킥오프 슬라이드 4장 (PPT를 PDF로 저장한 것) |
| 1호점_메뉴판.png | 칠판 메뉴판 |
| 기존_로고_2016.png | 지금 쓰는 옛 로고 |

기획서와 회의 자료에는 **일부러 서로 다른 곳이 두 군데** 있다. 2호점 오픈 시기(11월 말 / 12월 첫 주)와 브로셔 접지(3단 / 2단)다. EP7에서 AI가 이걸 찾아내는지 본다.

자료를 고치려면 `python s2/rec/make_materials.py`를 다시 돌린다(`shorts/`에서).

### 2. 화면 정리

- 브라우저 확대 **125%** (Ctrl + +). 영상이 세로라서 글씨가 커야 한다.
- 왼쪽 사이드바를 접는다. 지난 대화 목록이 보이면 안 된다.
- 이름·이메일이 보이는 계정 메뉴는 열지 않는다. 결제 정보도 찍지 않는다.
- 북마크바 숨기기(Ctrl+Shift+B), 다른 탭 닫기, Windows 알림 끄기.

### 3. 녹화 도구

- **Windows 게임 바:** 브라우저 창을 한 번 클릭한 뒤 **Win+Alt+R**로 시작, 다시 Win+Alt+R로 끝. 파일은 `동영상\캡처` 폴더에 저장된다.
- 회사 PC에서 게임 바가 막혀 있으면 OBS Studio로 브라우저 창을 녹화한다.
- 마우스는 천천히. 클릭하기 전에 0.5초 멈춘다.
- **한 컷 = 한 파일.** 실수하면 그 컷만 다시 찍는다.
- 지시문은 아래에서 복사해서 붙여 넣는다. 영상에서 지시문은 큰 글씨로 다시 보여 준다.

### 4. 파일 이름

찍은 파일을 컷 번호로 이름을 바꿔 `shorts/s2/rec/raw/`에 넣는다: `6-1.mp4`, `6-2.mp4` … 이 폴더는 저장소에 올라가지 않는다.

## 컷 목록

### EP6 claude.ai에서 시작하기

**6-1 접속** (10초)
새 탭 → 주소창에 `claude.ai` 입력 → 첫 화면이 뜰 때까지. 로그인돼 있지 않으면 로그인 화면까지만 찍고 끝낸다. 로그인은 녹화 밖에서 한다.

**6-2 프로젝트 만들기** (1분)
프로젝트 메뉴 → 새 프로젝트 → 이름 `모닝빵 2호점 리브랜딩` → 만들기. 이어서 프로젝트 지침(Instructions) 칸에 아래를 붙여 넣고 저장.

```
우리는 디자인 스튜디오 픽셀공방이고, 이 프로젝트는 모닝빵 베이커리 2호점 리브랜딩이야.
- 나는 최종 결정을 하는 CDO야. 결정은 내가 하고, 너는 선택지와 근거를 가져와.
- 자료에 없는 사실은 지어내지 말고 '확인 필요'라고 표시해.
- 시안은 방향이 겹치지 않게 여러 개를 내.
- 답은 짧게, 번호를 붙여서.
```

**6-3 Design 위치와 요금제** (20초)
Design 캔버스를 여는 곳을 보여 준다(화면에 보이는 메뉴 이름 그대로). 이어서 설정 → 요금제 화면에서 지금 요금제 이름만 보여 준다. 카드 번호 같은 결제 정보는 찍지 않는다.
이 컷으로 "Design은 어느 요금제에서 쓸 수 있는지"를 확정해 EP6 대사에 넣는다.

### EP7 자료 던지기

**7-1 자료 올리기** (20초)
프로젝트 화면의 파일(프로젝트 지식) 칸에 자료 4개를 한꺼번에 끌어다 놓는다. 올라간 목록이 보일 때까지.

**7-2 첫 지시** (답이 끝날 때까지)
프로젝트 안에서 새 대화 → 아래를 붙여 넣고 보내기 → 답이 끝까지 나오면, 위에서 아래로 천천히 스크롤.

```
올린 자료 네 개를 전부 읽고, 시키기 전에 파악한 것부터 보고해.
1) 이 가게의 강점
2) 2호점이 노리는 손님
3) 자료끼리 서로 안 맞는 부분
4) 자료만으로는 알 수 없는 것
```

AI가 안 맞는 부분을 못 찾아도 그대로 둔다. 그것도 영상 소재가 된다.

### EP8 팀 소집

**8-1 역할 회의** (답이 끝날 때까지)
같은 대화에서 이어서 보낸다 → 답이 끝나면 천천히 스크롤.

```
지금부터 회의야. 시장분석가, 기획자, 디자이너, 카피라이터, 비평가가 차례로 의견을 내 줘.
비평가는 앞사람들 의견의 약점을 짚어 줘. 한 사람당 세 줄 이내로.
```

**8-2 조사와 출처** (답이 끝날 때까지 + 링크 확인)
웹 검색이 꺼져 있으면 입력창 근처 도구 메뉴에서 켠다. 아래를 보낸다 → 답이 끝나면 **출처 링크 하나를 눌러** 새 탭에서 열리는 것까지 → 원래 탭으로 돌아와 끝.

```
다른 동네 빵집이나 베이커리 브랜드 로고는 요즘 어떤 경향이야?
웹에서 찾아보고 근거마다 출처 링크를 붙여 줘. 확인 못 한 건 확인 못 했다고 해.
```

### (선택) 9-1 로고 시안: 3부 EP9용

Design 캔버스를 열고 아래를 보낸다 → 시안이 다 나올 때까지.

```
모닝빵 베이커리 2호점 오픈해. 2012년부터 동네에서 새벽마다 빵 굽는 집이야.
로고 리뉴얼 시안 열두 개 뽑아 줘. 방향은 다 다르게.
```

1부에서 보여 준 로고 시안과 같은 지시문이다. 결과는 달라도 된다.

## 다 찍은 뒤

파일을 `shorts/s2/rec/raw/`에 넣고 알려 주면 이렇게 진행한다.

1. 컷마다 쓸 구간과 확대할 영역을 정해 클립으로 만든다: `python lib/clip.py s2/rec/raw/7-2.mp4 s2/rec/clips/ep07_report.mp4 --from 3 --to 48 --crop 960:1200:480:60`
2. 실제 화면과 AI의 실제 답에 맞춰 대사를 고친다.
3. 장면에서 `<canvas data-src="../rec/clips/ep07_report.mp4" width="960" height="1200">`과 `clip(캔버스, t, 시작, 길이, 녹화본 a초, b초)`로 넣는다. 답을 기다리는 긴 구간은 빨리 감기로 줄어든다.
4. 내레이션을 만들고 렌더링한다.

2. 프로젝트를 하나 만드세요. 이름은 [[모닝빵 2호점 리브랜딩]].

**EP7 자료 던지기**
1. 회의 전에 자료부터 던져요. 기획서, 회의 자료, 메뉴판까지 [[있는 그대로]].

3. (AI의 실제 답을 보고 채움. 예: 기획서는 11월 말, 회의 자료는 12월 첫 주. [[서로 다른 곳]]까지 찾아왔어요.)

**EP8 팀 소집**
1. 이제 팀을 부를 차례. 분석가, 기획자, 디자이너, 카피라이터, 비평가. [[각자 의견]]을 내 달라고 해요.

3. 다른 가게 조사도 시켜요. 단, [[출처를 붙여서]].
4. 링크를 눌러 [[진짜 있는 글인지]] 확인하는 건 사수 몫이에요.
5. 결론: 조사는 AI가, [[확인은 내가]]
