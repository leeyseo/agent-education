# 시리즈 기획

AI를 검색창으로만 쓰던 홈페이지 제작 업체가, 에이전트에게 일을 맡기고 디렉팅하는 법까지 배우게 하는 세로 숏츠 19편이다.

## 대상과 목표

| 항목 | 내용 |
| --- | --- |
| 대상 | 정적 HTML 사이트를 만들어 카페24 호스팅에 FTP로 올리는 소규모 디자인·홈페이지 제작 업체의 대표, 기획자, 디자이너, 퍼블리셔 |
| 지금 AI 수준 | 제미나이·코파일럿에 질문하거나, 코드를 붙여넣고 답을 복사해 오는 정도 |
| 지금 작업 순서 | 회의 → 기획 PPT → 포토샵 시안 → 퍼블리셔 마크업 → FTP 폴더 업로드 |
| 다 보고 나면 | 1) 검색·챗봇·에이전트의 차이를 설명한다 2) 작업 단계마다 에이전트에게 무엇을 시킬지 안다 3) 그냥 맡기지 않고 의심하고 캐물으며 디렉팅해야 하는 이유와 방법을 안다 |

## 핵심 비유

에이전트는 **의욕 넘치는 천재 신입 '열정이'**, 시청자는 **열정이의 사수**다. 손은 엄청 빠르지만 시키지 않은 일까지 하고, 확인 없이 "다 했습니다!"라고 한다. 그래서 앞부분은 "신입이 이렇게 일을 잘한다", 뒷부분은 "그래서 사수가 이렇게 다룬다"로 이어진다.

## 가상 세계관

3인 제작사 '픽셀공방'이 동네 빵집 '모닝빵 베이커리' 홈페이지를 리뉴얼하는 이야기로 19편을 잇는다.

| 인물 | 역할 | 영상에서 |
| --- | --- | --- |
| 김기획 | 대표 겸 기획자, 15년차. AI는 "네이버 검색 같은 것" | 시청자의 대리인. 놀라고 의심하다 사수가 된다 |
| 최시안 | 디자이너. 포토샵 시안 3개에 사흘 | 2부부터 '보는 눈'(피드백) 담당 |
| 박태그 | 퍼블리셔. 헤더 복붙, FileZilla로 업로드 | 에이전트를 직접 다루는 실무자. 사고도 먼저 겪는다 |
| 열정이 | 신입 = 에이전트의 의인화 | 민트 후드티, 동그란 안경, NEW 명찰 |
| 모닝빵 사장님 | 고객 | "인스타 보고 오는 손님이 많은데 폰에서 다 깨져요" |

- 기존 사이트: 2016년식 정적 HTML 12페이지. 페이지마다 헤더 복붙, 모바일 대응 없음, 카페24 FTP.
- 리뉴얼 요구: 폰에서 잘 보이게, 메뉴·가격 쉽게 수정, 오시는 길, 단체주문 문의, 인스타 연결.

## 구성

| 부 | 편 | 화면 표시 |
| --- | --- | --- |
| 예고편 | EP0 | 주황 '예고편' |
| 1부 에이전트가 뭔데? | EP1~EP5 | 검정 '1부' 칩 (EP1은 '① 검색 → ② 챗봇 → ③ 에이전트') |
| 2부 작업 순서가 바뀐다 | EP6~EP11 | 파랑 '회의 › 진단 › 레퍼런스 › 시안 › 피드백 › 배포' 중 현재 단계 |
| 3부 신입 사고 일지 | EP12~EP14 | 빨강 '사고 #1~3' |
| 4부 사수의 기술 | EP15~EP18 | 민트 '기술 #1~3', EP18은 '피날레' |

편별 대사는 [02-에피소드-대본](02-에피소드-대본.md)에 있다.

## 화면 원칙

- 세로 1080x1920, 30fps. 편당 20~45초.
- 매 편 구조: 결과·훅 먼저 → 예전 방식 → 에이전트 방식 → '오늘의 결론' 카드.
- 반복 장치: '예전'(회색) / '이제'(민트) 태그, 한 줄 결론 카드, 같은 빵집 사이트 모형(시안 A/B/C).
- 화면은 전부 모형(mock)이다. 실제 작업 녹화로 바꿀 수 있게 장면을 짧게 나눴다.
- 아래쪽 약 300px은 쇼츠 앱 UI가 덮으므로 비운다. 자막은 y=1380 근처.
