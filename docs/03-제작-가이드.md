# 제작 가이드

한 편은 `script.json`(대사)과 `index.html`(장면) 두 파일로 만든다. 나머지는 `shorts/lib/`의 공통 엔진이 처리한다.

## 전체 흐름

```
script.json ──▶ lib/build.py ──▶ audio/line_XX.wav, audio/narration.wav, timeline.js
                 (ElevenLabs로 줄마다 읽고, 앞뒤 무음을 잘라
                  장면·자막·단어 시각을 계산)

index.html + lib/engine.js ──▶ seek(t): 시간 t의 화면을 그대로 그림
                                 (모든 움직임은 t로만 정해짐)

lib/render.py ──▶ Chrome(Playwright)으로 1/30초마다 seek(t) 후 캡처
                  → ffmpeg로 H.264 + 내레이션 AAC → mp4
```

장면 길이는 음성 길이에 맞춰 자동으로 정해진다. 대사를 고치고 `build.py`를 다시 돌리면 장면·자막 타이밍이 함께 바뀐다.

## 새 편 만들기

1. 폴더를 만든다: `shorts/ep19/`
2. `script.json`을 쓴다 (아래 형식).
3. 비슷한 편의 `index.html`을 복사해 장면을 고친다.
4. `python lib/build.py ep19` → `python lib/sheet.py ep19`로 확인 → 고치기 → `python lib/render.py ep19`

## script.json

```json
{
  "ep": 19,
  "title": "화면 위쪽에 나오는 제목",
  "file": "EP19_파일이름.mp4",
  "header": {"chips": ["4부 · 사수의 기술", "기술 #4"], "on": 1, "color": "#1FB394", "size": 26},
  "say": {"5,000줄": "오천 줄"},
  "scenes": [
    {"id": "s1", "lead": 0.3, "tail": 0.6, "lines": ["첫 장면 대사. [[강조할 말]]은 노란 자막."]},
    {"id": "s2", "lead": 0.4, "tail": 2.0, "lines": ["한 장면에 여러 줄도 된다.", "줄 사이는 0.35초 쉰다."]}
  ]
}
```

| 필드 | 뜻 |
| --- | --- |
| `header.chips`, `on`, `color`, `size` | 제목 아래 칩. `on`번째 칩만 `color`로 칠한다. 칩이 많으면 `size`로 글자를 줄인다 |
| `say` | 화면 글자는 그대로 두고 읽을 때만 바꿀 말. `CLAUDE.md`, `Claude Code`, `FTP`, `HTML`, `AI` 등은 `lib/build.py`의 `SAY`에 이미 있다 |
| `lead` / `tail` | 장면 시작 후 첫 대사까지 / 마지막 대사 후 장면 끝까지(초). 결론 장면은 `tail`을 2초 정도로 |
| `lines` | 내레이션. 쉼표·마침표 단위로 자막이 나뉜다(4글자 미만 조각은 다음과 합침) |

## index.html

```html
<link rel="stylesheet" href="../lib/base.css">
...
<div id="viewport"><div id="stage"><div class="abs" id="area">
  <div class="scene" id="s1"> ... </div>     <!-- script.json의 장면 id와 같게 -->
</div></div></div>
<script src="timeline.js"></script>
<script src="../lib/engine.js"></script>
<script>
start({
  s1(t, d, m, W) {            // t: 장면 안 시각, d: 장면 길이, m: 자막 덩어리 시작 시각들, W: 단어별 시각
    rise($('s1-card'), t, 0.2);                 // 0.2초에 아래에서 떠오름
    pop($('s1-st'), t, when(W, '사고') - 0.1);  // '사고'라고 말하기 직전에 튀어나옴
  },
});
</script>
```

상단 제목·칩·자막·재생 버튼은 엔진이 자동으로 만든다. `#area`는 화면의 x 60~1020, y 400~1320 영역(960x920)이다.

### 애니메이션 도우미 (`lib/engine.js`)

| 함수 | 하는 일 |
| --- | --- |
| `rise(el, t, at, dur, dist)` | 아래에서 떠오르며 나타남 |
| `slide(el, t, at, dur, dist)` | 옆에서 밀려 들어옴 (dist가 음수면 왼쪽에서) |
| `pop(el, t, at, dur, rotate)` | 톡 튀어나옴. 스티커·도장에 |
| `fade` / `hide` | 나타남 / 사라짐 |
| `put(el, opacity, y, scale, rotate, x)` | 직접 위치 지정 |
| `typeText(el, text, t, at, cps)` | 타자 치듯 글자 입력 |
| `meterTo(el, t, at, dur, pct)` / `countTo(el, t, at, dur, n, fmt)` | 막대 채우기 / 숫자 올라가기 |
| `when(W, '단어', 기본값)` | 그 단어를 말하기 시작하는 시각. 대사와 화면을 맞출 때 쓴다 |
| `spin(t)`, `blink(t)` | 진행 중 표시, 깜빡이는 커서 |
| `siteMock(v, btnStyle)` | 빵집 사이트 모형 HTML (버튼 모양을 바꿀 때) |

### 캐릭터·아이콘·사이트 모형

| `data-char="person:누구:표정"` | `sian`(최시안) `tag`(박태그) `owner`(모닝빵 사장님), 표정은 열정이와 같음 |
| `data-icon="이름:색"` | `mag` `folder` `file` `lock` `key` `save` `warn` `check` `x` `trash` `cloud` |
| `data-site="종류:배율"` | 빵집 사이트. `A`(주황) `B`(민트) `C`(어두운 고급) `broken`(폰에서 깨진 A) `old`(2016년식). 배율은 글자·여백 크기 |

## 디자이너 편 (`shorts/s2/`)

같은 엔진을 쓰고, 폴더가 한 단계 깊다.

- 명령: `python lib/build.py s2/ep01`, `python lib/sheet.py s2/ep01`, `python lib/render.py s2/ep01`
- `index.html`의 경로: `../../lib/base.css`, `../../lib/engine.js`, 그리고 이 시리즈 공통 `../s2.css`, `../s2.js` (engine.js 다음, 장면 스크립트 앞)
- `script.json`에 `"series": "AI 신입 길들이기 · 디자이너 편"`을 넣으면 상단 알약 글자가 바뀐다

### 실제 시안 넣기

1. Claude의 Design 캔버스로 시안을 만든다. 캔버스 원본은 `s2/design/<작업>/project/`에 둔다(`canvas.json` + 아트보드마다 `.dc.html`). 아트보드는 템플릿 구멍(`{{ }}`) 없이 정적 마크업으로 써야 로컬에서도 똑같이 찍힌다.
2. `python lib/snap.py s2/design/logo` → `s2/design/logo/png/<아트보드 이름>.png`
   - 늘었다 줄었다 하는 페이지(홈페이지)는 폭을 바꿔 찍는다: `python lib/snap.py s2/design/homepage --width 390 Main` → `png/Main@390.png` (내용 높이 전체)
   - 인쇄물은 아트보드를 한 쪽씩 묶어 PDF로: `python lib/snap.py s2/design/brochure --pdf 모닝빵_2호점_브로셔_A.pdf LA-out LA-in` → `pdf/` 폴더. 화면 그대로(RGB, 재단 여백 없음)라 인쇄 입고용은 따로 맞춘다
   - 다시 찍은 PNG는 글꼴 렌더링 때문에 컴퓨터마다 몇 픽셀 달라질 수 있다. 시안을 고치지 않았다면 바뀐 PNG는 커밋하지 않는다
3. 장면에서 쓴다.

| 쓰는 법 | 결과 |
| --- | --- |
| `<div class="lg" data-logo="B1">` | 그 시안 카드 |
| `<div class="lgrid4" id="s4-grid" data-r1>` | 1차 시안 12개 격자. 칸은 `cell('s4-grid', 2)` |
| `mark('s4-grid', 6, 'x', '버려', t, at)` | 판정 표시. `x`(버려·빨강) `o`(살려·민트) `t`(보강·노랑) |
| 칸에 `.dim` / `.pick` | 흐리게(버린 시안) / 민트 테두리(고른 시안) |
| `<div class="real">실제 Claude 결과물</div>` | 실제 결과물 꼬리표. 모형 화면에는 `예시 화면` 꼬리표를 따로 단다 |
| `<img src="../design/brochure/png/LA-out.png">` | 로고가 아닌 시안(브로셔·홈페이지)은 편 안에서 그림을 직접 넣는다. EP10의 `.bro`, EP11의 `.shot`·`.ph`(폰 틀) 참고 |
| 확대경 | 그림 일부를 크게: 겉 상자에 `overflow: hidden`, 안의 `<img>`를 배율만큼 키우고 `left`·`top`을 음수로. 자리는 PNG 픽셀을 재서 맞춘다(EP9 `.lens`, EP10·EP11 `.crop`) |
| `<div data-chair>` | CDO 의자 (인물 뒤에 깐다) |

### 화면 녹화 넣기

1. 녹화 원본을 `s2/rec/raw/`에 둔다 (찍는 법: [07-2부-촬영-가이드](07-2부-촬영-가이드.md)).
2. `python lib/clip.py s2/rec/raw/7-2.mp4 s2/rec/clips/ep07_report.mp4 --from 3 --to 48 --crop 960:1200:480:60`로 구간과 영역을 잘라 클립을 만든다. 소리는 버리고 모든 프레임을 키프레임으로 만든다.
3. 장면에 `<canvas data-src="../rec/clips/ep07_report.mp4" width="960" height="1200">`을 놓고, 장면 함수에서 `clip(캔버스, t, 시작, 길이, a, b)`를 부른다. 장면 시각 `시작`~`시작+길이` 동안 녹화본의 a~b초를 보여 준다. 답을 기다리는 긴 구간은 그만큼 빨리 감긴다.

엔진은 숨긴 `<video>`로 탐색하고, 탐색이 끝난 프레임을 캔버스에 그린다. 렌더러는 프레임마다 탐색이 끝나기를 기다리므로 프레임이 정확히 맞는다. `<video>`를 화면에 직접 놓으면 화면 갱신이 늦어 이전 프레임이 찍힐 수 있다.

### 캐릭터 추가분

- `data-char="yj:stand:smile:analyst"`: 열정이 분신. 넷째 칸이 역할 `analyst`(분석) `planner`(기획) `designer`(디자인) `copy`(카피) `critic`(비평). 모자와 명찰이 바뀐다
- `data-char="person:junior:sad"`: 사람 신입 (사원증)
- 표정 `skeptic`(입 삐죽)은 열정이·인물 모두에 쓸 수 있다

### 주의

- 이미지가 있는 편은 엔진이 이미지 로딩까지 기다린 뒤 첫 프레임을 그린다.
- `[[강조]]` 안에 쉼표를 넣지 않는다. 자막이 쉼표에서 나뉘면서 강조가 깨진다. 예: `고르고, 버리고, [[다시 시키기]]`
- 인용 끝의 따옴표(`'`)도 글자 수에 들어간다. `'네, 바로요!'`는 쉼표에서 자막이 갈린다.

### 자주 겪은 문제

| 증상 | 원인과 해결 |
| --- | --- |
| 표시가 프레임마다 깜빡임 | `classList.toggle(이름, undefined)`는 강제값이 아니라 뒤집기로 동작한다. `!!`로 불리언을 넘긴다 |
| 페이지가 준비되지 않음 | 전역 함수 이름이 브라우저 예약어(`top`, `parent`, `self` 등)와 겹침. `render.py`가 페이지 오류를 출력한다 |
| 화면이 대사보다 일찍 나옴 | `when()`이 다른 단어의 일부에 걸림 (예: '안'이 '시안을'에 걸림). 더 긴 단어로 찾는다 |
| 결론 카드가 한 문장 일찍 나옴 | `m[i]`는 줄이 아니라 자막 덩어리 기준이다. `when()`으로 맞추는 편이 안전하다 |
| 글씨가 작아 보임 | 쇼츠는 폰 화면이다. 본문 30px, 강조 40px 이상을 기준으로 |

## 속도와 톤 기준

- 지금 속도(편당 20~45초, 줄 사이 0.35초)가 기준이다. 2배 빠르게 줄이고 효과음·비트를 넣은 실험은 "너무 빠르다"는 피드백으로 되돌렸다(`shorts/ep01/_v2/`).
- 기계음(Windows 기본 음성)은 쓰지 않는다.
- 첫 3초 안에 결과나 갈등을 보여준다.
